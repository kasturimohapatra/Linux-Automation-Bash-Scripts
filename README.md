# 🧠 Enhanced Linux Automation Using Bash Scripts

## 📋 Project Overview
This project automates routine Linux administration tasks using custom Bash scripts.  
It includes automated updates, log monitoring, backup creation, and a menu-driven control system for ease of use.

## 💡 Novelty (Extended Capstone Feature)
> **Novelty Added:**  
> This project extends the existing Capstone by introducing **custom automation workflows** that simplify and speed up system maintenance.  
> Features include:  
> - A **menu-driven interface** to trigger automation tasks  
> - **Log file monitoring** with alerts  
> - **Automated system cleanup and updates**  
> - **Backup management scripts**  
>   
> These extensions make the project more practical, interactive, and adaptable to real-world Linux environments.
